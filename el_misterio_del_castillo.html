Guía del profesor · Personalización y publicación

Las preguntas se encuentran en el bloque QUESTION_BANK del JavaScript, al final de este archivo. Cada nivel tiene title, grammar, dialogue, hints y questions. Puede añadir, quitar o editar preguntas. Use type:"input" para escribir una conjugación, type:"choice" para seleccionar una opción, o type:"story" para completar una frase del relato. Cada pregunta necesita prompt, answer, explanation y, si es de selección, options.

La puntuación concede 100 puntos por respuesta correcta al primer intento, 60 al segundo y 30 a partir del tercero. La precisión mide aciertos al primer intento entre preguntas contestadas por primera vez. Se permiten tres pistas por nivel; no se restan puntos por usarlas. El juego permite repetir sin perder avances previos hasta que se elija «Reiniciar».

Para publicar: suba este archivo como index.html a un repositorio público de GitHub; en Settings → Pages, seleccione «Deploy from a branch», rama main y carpeta /(root). Abra la dirección publicada, compruebe el juego y, en Google Sites, use Insertar → Insertar → URL para pegar esa dirección. Ajuste la altura del marco. Los datos se guardan por navegador y no se envían al profesor.
